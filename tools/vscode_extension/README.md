# Legacy Language Support — VS Code Extension

This extension package preserves editor support created for the former Nervestack / NSPL language identity. The package name, language identifier, grammar scope and `.nspl` file extension are retained for compatibility with existing files and tooling; they are historical identifiers, not approved successor branding.

The Programming Language (PL) Division Unit is **CLOSED / NOT OPERATING**. This archived extension is not an announcement of active product development or ongoing support.

## Preserved features

- Syntax highlighting for legacy `.NSPL` / `.nspl` files.
- Comment toggling.
- Bracket matching.

## Installation

1. Install the existing `.vsix` package if you need to work with legacy files.
2. Open a legacy `.NSPL` / `.nspl` file.

No successor language identifier, extension or publisher identity has been selected.
